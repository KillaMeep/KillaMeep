<h2 align="center">Things I've built</h2>

<table>
  <tr>
    <td width="50%" valign="top">
      <h3><img src="https://www.killameep.com/assets/img/waypoint.svg" width="26" align="top" alt="" />&nbsp;<a href="https://github.com/KillaMeep/waypoint-osint">Waypoint</a></h3>
      Free, open-source image geolocation. Give it one outdoor photo and it estimates where on Earth it was taken: a diffusion model makes coarse guesses, sun position rules out bad ones, and street-level matches confirm the rest. Now a native Rust engine, no Python to install.

      <code>Tauri</code> <code>Rust</code> <code>ONNX Runtime</code> <code>LightGlue</code> <code>OSINT</code>

      A desktop app that turns images and videos into ASCII art. Color or grayscale, a pile of character sets (including braille and custom ones), live tuning, and export to TXT, HTML, PNG or animated GIF.
      <br/><br/>
      <code>Electron</code> <code>JavaScript</code> <code>FFmpeg</code>
    </td>

      <code>Python</code> <code>YOLOv5</code> <code>PyTorch</code> <code>Computer vision</code>
